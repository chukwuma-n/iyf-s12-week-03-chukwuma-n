## What I Learned

During Week 03, I learned how to use Git and the command line as part of a practical development workflow.

Key lessons include:

* How to check my current directory and navigate using command-line tools.
* How to track files with Git using `git add`.
* How to create meaningful commits with `git commit`.
* How to push local changes to GitHub.
* How to create, switch between, merge, and delete Git branches.
* How feature branches help separate development work from the main branch.
* How shell scripts can automate repetitive project setup tasks.
* How `.gitignore` prevents unwanted files from being tracked.
* How GitHub pull requests support collaboration, review, and approval.
* How to identify and resolve merge conflicts.

## Challenges Faced

One challenge was understanding how local Git branches relate to branches on GitHub. I also had to become more comfortable with the difference between committing changes locally and pushing those commits to the remote repository.

Another challenge was understanding why Git sometimes reports untracked files and how to deliberately stage only the files that belong in a particular commit.

Working through these tasks helped me understand Git as a workflow rather than simply a way to upload files.
